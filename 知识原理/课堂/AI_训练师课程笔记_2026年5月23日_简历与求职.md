## 二、面试的底层逻辑

### 1. 面试 = 互相筛选 = 供求关系

> "越稀缺的能力越值钱，面试就是供需关系。所以面试前一定要知道自己的稀缺性是什么。"

### 2. 求职是一个"漏斗"，每一层 ≈ 50% 通过率

```
打招呼  →  一面  →  二面  →  三面  →  背调  →  offer
（每一关大约 50% 通过率）
```

- **打招呼**：解决"无回"（最扎心的就是海投后没人鸟）
- **一面**：万事开头难，接到一面，二面通过率大幅提高
- **二面**：让人家"一锤定音"
- **三面**（字节、阿里、管理岗常见）：看个人素质，相当于"订婚"，已经一只脚进门
- **背调**：最怕"临阵脱逃"——比如简历写"正岗"，HR 要流水时自己怂了改口说"外包"，心态崩溃

### 3. 两个核心抓手

- **数量要多**：能保证 2000 个打招呼，最后 offer 一定多
- **质量要高**：质量取决于简历 + 面试表达

## 三、AI 训练师在公司的位置（组织架构）

老师以阿里"千问"团队为例画了一遍：

```
AI 产品经理（负责一条线，如千问）
├─ 模块 1：AI 换装
├─ 模块 2：AI 模板
├─ 模块 3：AI 视频
└─ 模块 N：AI 客服 …
        │
        ├─ 初级 AI 产品经理
        ├─ 数据运营
        ├─ 项目经理 / AI 训练师（常常是一人多岗）
        ├─ 数据标注
        ├─ 质检
        └─ 评测岗
```

要点：
- **AI 训练师不是一个岗位，是一个工作流**，类似"炒菜"包含洗菜、切菜、配料、火候等多个动词。
- 找工作时**搜商很重要**：可以搜 数据运营、SNS、项目经理、AI 项目经理、评测岗、质检、数据标注。
- **数据流转链路**：产品经理提需求 → 数据运营 + 产品经理一起 → 给训练师/项目经理 → 写规则文档 → 标注 → 质检 → 评测。
- 项目优先级 P0 ~ P3：
  - **P0**：难度高 + 专业度高 + 紧急
  - **P1**：难度高，专业度稍低，不一定特别急
  - **P2**：已有经验，复制即可（专业度可能更高，急不急另说）
  - **P3**：在 P2 基础上的优化，增加工作量

## 四、薪资 & 工作年限的"人设"

老师反复强调：**工作年限 = 工作人设**，出门在外身份是自己给的。

| 工作年限 | 人设定位 | 关键能力 |
|---------|---------|---------|
| 1–3 年 | 性价比之王（"老牛马"） | 实习经验可以加进去凑年限 |
| 3–5 年 | 中流砥柱 | 能解决棘手/创新问题；多维度标签体系构建；新业务线挑大梁；至少干过 P1 + P2，野心大可加 P0 |
| 5–10 年 | 独挑一个大梁 | 至少带 1–2 个中流砥柱 + 几个 P1/P2；架构能力 |

**重要"分水岭"**：
- 26–27 岁如果还没拿到**年薪 40 万**，后续职场会很坎坷
- 年薪 40 万 ≈ 月薪 26K × 15 薪，手底下带 1–2 个实习/小兵
- 5 年以上的"管理岗"：相当于阿里 P7 / P8 级别（现在职级被稀释，多了 7.3 / 7.5 / 7.6 / 7.9 等中间档）

#### (3) 个人优势的 4 大维度

老师在白板上画的核心结构 ↓

```
个人优势 = 专业能力  +  管理能力  +  提效能力  +  个人素质
```

| 维度 | 写什么 |
|------|--------|
| **专业能力** | ① 全流程标注管理（标注全流程必须刻进肌肉记忆）<br>② 专项数据能力（行业 + 数据类型） |
| **管理能力** | 管理过几个人？3 人 / 10 人 / 20 人 / 200 人都可以写。直播间老师给 200–300 大学生导师分活，这就是"专职 + 外包 + 兼职"管理 |
| **提效能力** | 自动化工具、Python 脚本数量（人家写 1 个，你写 20 个就稀缺） |
| **个人素质** | 英语、设计、心理学、自媒体、摄影、英文论文学习能力等 |

#### (4) 稀缺性的判断标准

- "98% 交付准确率" → **不是**稀缺（教育要 99.5%）
- "整理 bad case" → **不是**稀缺（人人都做）
- "管理经验" → **是**稀缺
- "全流程能闭环" → **是**稀缺
- "自学过英文论文/期刊" → **是**稀缺（学习能力 + 文字输出能力）
- "运营/产品全栈" → **是**稀缺（维度广）
- "自媒体 + 对 AI 真实热情" → **是**稀缺

#### (5) 高级简历范例（35K 那份）的关键词

**20K 以上的分水岭**：能不能讲清楚从"行业 → 产品 → 业务 → 技术 → 模型 → 数据"这套完整架构。
**性价比牛马**：了解到业务/技术层就够了。

#### 行业案例对照表

##### A. 教育（作业帮 / 网易有道）
- 功能：拍搜、批改作业、AI 对话
- 技术层：OCR（Optical Character Recognition，光学字符识别）→ RAG（Retrieval-Augmented Generation，检索增强生成）→ 逻辑处理 → 任务规划 → 多轮对话
- 行业特性：教育不能错，准确率必须 99.5%（"祖国的花朵不能搞错"）
- 数据特点：偏产品经理风格，标注质检策略

##### B. 医疗（复星健康 / 严肃医疗）
- 产品功能：医学工具、健康问答、在线问诊、买药
- 用户端：医生、患者、医院、药企、医药代表 → **多端 crazy**（医疗特殊性）
- 技术层：RAG + agent
- 强调：每个功能要赋能不同端（如医学工具只赋能医生）

##### C. 旅游（飞猪 AI）—— 完整架构示例
- **数据底层**：知识库（给 RAG 用）
- **模型层**：多个模型分工
  - 有的做 embedding（嵌入）
  - 有的做 re-rank（重排）
  - 有的做多模态
  - 调用量大的场景用便宜模型
- **平台层**：
  - agent 开发
  - MCP（Model Context Protocol，模型上下文协议）调用工具
  - 长期记忆 / 短期记忆（用户数据）
  - 网关
- **Agent 层**：行程规划、酒店推荐、交通 agent、目的地 agent
- **对话层**：分享、消息管理、嵌套卡片（机票卡片、银联卡片、门票卡片、医疗里的药品卡片/医生卡片/医院卡片/处方卡片）
- **意图识别层**（agent 最重要）：
  - **场景**：售前 / 售中 / 售后（医疗就是问诊前/中/后）
  - **参数提取**：例如"我头疼，已经吃了药" = 病情参数 + 治疗阶段参数
  - **Query 改写**：因为中国用户基数大，表达极其嘈杂，需要兜底改写
- **通信协议层**：跟算法对接

#### "公共功能 = 用户 × 场景" 案例
- 我（用户）+ 晚上饿了（场景） → 需求 → 高频功能 → 点赞 / 浏览 / 选择 / 下单功能

## 七、写不出来怎么办？—— 让 AI 反过来采访你

老师讲的"上层功法"：

- **下层功法**：你提问 AI（受限于你的问题范围，答案有限）
- **上层功法**：让 AI 提问你
  - 把"我要写一份简历，来问我具体问题，我来回答，你来写"丢给 Claude / ChatGPT
  - 你被采访 → AI 自然帮你提炼
  - 这样写出来**没有 AI 味儿**，比你直接让 AI 生成强很多

## 九、BOSS 直聘投递实战

### 1. 平台优先级

1. BOSS 直聘
2. 智联招聘
3. **内推**（最快，可能直接到面试官手里）

### 2. 打招呼语 ——「15 字法则」

> **HR 后台只展示前 15 个字**，所以前 15 字必须信息密度拉满。

**公式**：工作年限 + 业务经验 + 岗位（如学历好可加学历）

❌ 错误打招呼：
- "你好，还招人吗？"
- "你好，请问什么岗位还在吗？我很感兴趣可以进一步沟通"（这是 BOSS 自带模板）

✅ 正确打招呼示例：
- "我是前夸克的项目经理，做过 AI 搜索用户意图，熟悉制定规则文档"
- "我拥有近两年的评测相关工作经验，接触过文生图标签挂载和 OCR 识别认图模型评测"
- "十年顺丰 …"（十年工作经验同学）

打招呼语分**简短版**和**复杂版**，每个项目可以单独写一条。

### 3. 已读不回的 4 个常见原因

| 问题 | 处理 |
|------|------|
| 学历 | 非全本科只写"本科"（不要写全称）；985/211 / 研究生才写出来 |
| 空窗期 | 合并同类项，5 年内不要超过 3 段工作经历（否则显得不稳定） |
| 到岗时间 | **必须写"随时到岗"**（不管是否在职）。原因：HR 基本工资+绩效，提成几百块，他会优先推"随时能上"的人 |
| 离职原因 | **必须客观**：搬家、跨城市、不可抗力。**绝对不能写**：钱少、岗位、领导、嫌活累、找到更好的 |

> 离职原因金句："你不能因为见色起意——人家更好就跳——那阿里也会觉得字节更好。所以一定要说客观原因。"

### 4. 谈薪小技巧

- 业务方超级认可你 + 你有其他 offer → 跟 HR 说**多要 1000–2000**
- HR 有谈薪权限，且推荐周期 1–2 周，他急
- 让 HR 觉得"你随时能入职 + 你还有别的 offer" → 主动权在你

### 5. BOSS 后台「偷偷搞动作」

进入【设置】关掉以下功能：
- **个性化推荐 / 大数据推荐**：默认会过滤掉比你期望薪资低的岗位，关掉后能看到全量（推荐先拿低薪练手）
- **位置推荐**：在山里/二级城市会被推乱七八糟岗位
- **iOS** 可以关位置，**安卓**联动关不了 → **多用网页端**
- **隐私权限管理**：账号与安全 → 权限管理 → 位置管理 → 删除并关闭
- 屏蔽以前公司（如果不希望前司同事看到你在找工作）

### 6. 投递节奏

- **150 家/天 × 10 天 = 1500 家**（海投起步量）
- **第一周**：投上海、北京、深圳（杭州先不投）
- **接到第一个口头 offer 后**，开始加投杭州（保底已经有，可以选）
- **避开阿里也想去阿里**的技巧：看公司位置——中软、医保等外包公司常常在替阿里/字节招人，工作地点写"阿里巴巴"的就是给阿里招

### 7. 面试节奏建议

- 一天**最多 2–3 家**，"过 2 家就行了"，别一天面 5 家把自己消耗光
- 10 个一面 → 7 个二面 → 几个三面 → 3 个 offer → 三选一
- **每场面试必须复盘**：录音转文字 → 给助教老师 → 助教逐题分析
- 一般复盘 2 次就能上班
- 主要问题就 2 个：①听不懂面试官在问什么 ②说到具体数据时卡壳

## 十、上班之后：周报 = 涨薪种子

老师给的"涨薪式上班"姿势：

1. **每周写周报**，把工作细节、数据、文档全部沉淀

跳槽节奏：
- **直接跳槽涨薪 ≈ 50%**

- 但前提是：周报、文档、数据全部备好

## 十一、自媒体 / 主业 + 副业的人生观（老师本节情绪最浓的部分）

> "35 岁所有人都会被裁。你的工作是别人给的，你的副业才是你自己的。"

### 核心观点

- **不要做 NPC**（Non-Player Character，非玩家角色）。可以用搜索引擎搜自己的名字，搜不到 = 在这个世界上"匆匆来匆匆走"。
- 《寻梦环游记》：最大的死亡是被遗忘。
- 把上班薪资的 **30% 时间**投到自媒体——这是你真正的"手牌"。
- **GEO 时代**（Generative Engine Optimization，生成式引擎优化）= content 时代，发出来才有被检索的可能。

### 实操建议

- 平台：小红书、公众号、头条号、百家号、爱范儿、人人都是产品经理
- 内容类型：**2 万字通识类文章**（行业概览、生态系统类）
  - 老师举例：自己写过《车载 HMI（Human-Machine Interface，人机交互界面）生态系统》通识文，因此拿到奔驰、东风等 ToB 咨询机会 → 进而开课闭环商业模式
- 视频自媒体：哪怕 1000 播放 = 1000 个人认识你（一个教室才 65 人）
- 关键心态：不发是 0，发了至少有"可能性"

### 老师强烈推荐的工具

- **AnkerGo（安克豆）录音工具**：能联动飞书，加速知识结构化
- 不要再用钉钉录音

## 十二、心态 & 行动哲学（金句合集）

- "你坐在这里，已经比 99% 的同学要好了。"
- "你吹多大的牛，面试时就要拿多少证据来兜底。"
- "千万别因为'人家说的'就给自己判定一个'我做不到'的基因。"
- "找工作本身就是被人挑选的过程。我不希望被挑选，所以我做自媒体。"
- "归零思维：到现在我也不觉得自己哪厉害，就是普通人，但一直在学习的路上。"
- "试探边界，这个边界永远比你想得宽得多得多。"
