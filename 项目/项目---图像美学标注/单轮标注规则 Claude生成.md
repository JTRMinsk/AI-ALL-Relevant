# 单轮标注规则

## 一、标注流程

对每一条数据，按以下顺序处理：

1. 通读 prompt，把里面的**所有约束**逐条记下来（数量、格式、禁用词、必含词、范围、风格要求等）。
2. 通读原response，逐条核对：约束是否全部满足 → 内容是否完整 → 事实是否正确。
3. 凡是不能 100% 确定的事实点（人名、作品归属、年份、数据、机构名等），**必须**通过查证后再判断，不要凭印象。
4. 标红错误位置 → 选定审核结果 → 按下方规则填写其余列。

## 二、关于原response 中已存在的红字

原数据中部分单元格存在 `<font color="#EB144C">...</font>` 标签包裹的红字。**这是数据本身的噪声，全部忽略**。请按"原文未做任何标记"来处理，自己重新审查、重新标红。

## 三、各列填写规则

### 1. 原response（错误标红）

- 错误位置用红色标出，颗粒度尽量精确到**最小错误单元**（具体的字、词、数据、人名、句子），不要整段标红。
- 如果是结构性错误（如缺总结段、违反禁用词），把违规的那个词/那一段标红即可。
- 如果整体方向就错了（完全没回答 prompt 或答非所问），整段标红。

### 2. 审核结果（三档之一）

- **通过**：满足 prompt 中所有约束，无事实错误，内容完整连贯，可直接作为训练数据。
- **不通过-改写**：存在 1 个或若干个明确错误，但整体框架可救，**最小改动**后即可作为训练数据。
- **舍弃**：满足以下任一条件：
  - prompt 本身有问题（语义歧义、无法回答、约束自相矛盾、违规违法）。
  - 原response 错误密度过高，改写成本接近重写（参考线：超过 1/3 内容需要重写）。
  - 关键事实/数据无法通过权威源核实。

### 3. 错误类型（多选；"不通过-改写"和"舍弃"必填）

下表为错误类型枚举，标注时直接选用其中的代号或名称。多个错误并存时全部勾选。

| 代号  | 名称       | 定义                             | 例子                                |
| --- | -------- | ------------------------------ | --------------------------------- |
| A   | 事实错误     | 具体信息不正确：人物、时间、地点、数据、归属等        | 把《浣溪沙·谁念西风独自凉》作者写成晏殊（实为纳兰性德）      |
| B   | 编造内容     | 捏造不存在的研究、引言、案例、名言              | 杜撰"一项研究表明..."但无任何出处；伪造名人名言        |
| C   | 约束-数量不符  | prompt 要求 N 个，response 给出非 N 个 | 要求 3 部电影，给出 5 部或只给出 2 部           |
| D   | 约束-禁用词违反 | prompt 明令禁用某词，response 出现了该词   | 要求"不得使用'团圆'"，response 出现"团圆节"     |
| E   | 约束-必含词缺失 | prompt 要求含某词，response 没有       | 要求每条祝福语都含"月亮"，某条没有                |
| F   | 约束-格式不符  | 不满足指定格式（总分总、分点、字数、轮数等）         | 要求总分总，response 缺总结段               |
| G   | 约束-其他未满足 | 其他类型约束未满足                      | 要求"避免提及个人生活信息"，response 写了出生日期/籍贯 |
| H   | 理解偏差     | 误解 prompt 核心意图                 | 要求"分别"讲两部作品，response 把两部混着讲       |
| I   | 内容截断     | response 在表达完成前中断              | 句子戛然而止、列表只列到一半                    |
| J   | 逻辑/常识错误  | 自相矛盾、违反基本常识                    | 同一段里前后结论冲突；把同一品牌当成两个品牌推荐          |
| K   | 冗余/无关    | 加入偏离主题的内容、过度铺垫                 | 大篇幅写无关背景，挤压正文                     |
| L   | 表达质量差    | 语句不通、用词混乱、复述 prompt            | 把 prompt 原话当作答案的一部分               |

### 4. 问题备注

用一两句话说明具体问题，需具体到错在哪、为什么错。

例：
- "《浣溪沙·谁念西风独自凉》作者为纳兰性德，原response 错署为晏殊。"
- "prompt 要 3 部，原response 自行加了'近五年'限制后只给出 2 部完整内容，且第 1 部 2014 年不在近五年范围内。"

### 5. 舍弃原因（仅"舍弃"档必填）

明确写出对应上面"舍弃"三种情形中的哪一种，并简述原因。

例：
- "prompt 约束矛盾：要求列三个反映 X 的事件，但同时限制了所有可能符合的范围。"
- "原response 通篇事实错误，9 处数据/归属错误，改写成本超过重写。"

### 6. 优质源

- 用于支撑错误判定和改写依据的权威信息来源。
- 默认 URL 中的信息为权威信息。**遇到不确定的，一律点进去查证后再做判断**。
- 一条来源：直接贴 URL。
- 多条来源：每条 URL 前简注它支撑的内容点，例如：

  ```
  作者归属核实：https://...
  GDP 数据核实：https://...
  ```

- "通过"档可不填；"不通过-改写"档建议填（特别是涉及事实修正时）；"舍弃"档可选。

### 7. 交付response（改写标绿）（仅"不通过-改写"档必填）

- **在原response 基础上做最小改动**：保留所有正确的部分，只改错的地方。
- 新增/修改的字、词、句用**绿色标出**；删除的内容直接删除，不必标记。
- plus_response 仅供参考，**不允许整段复制 plus_response 作为交付**。
- 改完通读一遍，确认：
  - prompt 中所有约束都满足；
  - 整体语义连贯，没有改坏上下文；
  - 没有遗留的事实错误。

### 8. 标注人

填写本人姓名。

## 四、判断原则

1. **prompt 优先**：response 是否合格，首先看 prompt 中的显性约束是否全部满足。任一硬约束未满足，一律不能判"通过"。

2. **事实严于风格**：事实类错误（人名、年份、数据、归属、机构名）一律不放过。表达风格上的小瑕疵，只要不影响理解，可以容忍。

3. **不确定就查**：凡是自己不能 100% 确定的事实点，都要通过权威来源查证后再判断，不允许凭印象。

4. **改写最小化**：能改一个词就不改整句，能改一句就不改整段。保留原response 的整体结构和所有正确部分。

5. **截断视为错**：response 戛然而止判为"内容截断"（错误类型 I），按"不通过-改写"处理，需要把内容补完整。

6. **舍弃宁慢勿滥**：拿不定该不该舍弃时，先按"不通过-改写"尝试改一下；只有确认改写成本接近重写、或 prompt 本身就有问题时，才用舍弃。

## 五、快速自检清单

提交一条数据前对照过一遍：

- [ ] prompt 里所有显性约束（数量、格式、禁用词、必含词、范围）都点过一遍？
- [ ] 涉及的事实点都查证过？
- [ ] 错误类型勾选齐全（多选）？
- [ ] 问题备注写清楚了具体在哪儿错、错成什么？
- [ ] 若改写，绿字只标了改动处，且没有整段抄 plus_response？
- [ ] 若舍弃，舍弃原因明确对应上面三种情形之一？
